Политика обработки персональных данных

Согласие на обработку персональных данных

Дата последнего обновления: 2024

1. Общие положения

Настоящая Политика обработки персональных данных (далее — «Политика») разработана в соответствии с Федеральным законом «О персональных данных» и определяет порядок обработки и защиты персональных данных пользователей сервиса HeyMoney (далее — «Сервис», «Оператор»).

2. Оператор персональных данных

Оператором персональных данных является HeyMoney. Контактные данные: privacy@heymoney.ru

3. Категории обрабатываемых персональных данных

3.1. Персональные данные, предоставляемые пользователем

Оператор обрабатывает следующие категории персональных данных:

  • Адрес электронной почты
  • Реквизиты для пополнения (IBAN, BEP-20 адреса)
  • Информация о транзакциях
  • Иная информация, предоставляемая пользователем

3.2. Автоматически собираемые данные

При использовании Сервиса автоматически собираются:

  • IP-адрес
  • Информация о браузере и устройстве
  • Данные о посещении сайта (cookies, метаданные)
  • Логи доступа

4. Цели обработки персональных данных

Персональные данные обрабатываются в следующих целях:

  • Предоставление услуг Сервиса
  • Обработка транзакций и платежей
  • Идентификация пользователей (KYC)
  • Противодействие отмыванию денег (AML)
  • Соблюдение требований законодательства
  • Связь с пользователями
  • Улучшение качества сервиса
  • Предотвращение мошенничества
  • Обеспечение безопасности

5. Правовые основания обработки

Обработка персональных данных осуществляется на основании:

  • Согласия субъекта персональных данных
  • Исполнения договора, стороной которого является субъект персональных данных
  • Соблюдения требований законодательства
  • Защиты жизненно важных интересов

6. Способы обработки персональных данных

Обработка персональных данных осуществляется с использованием средств автоматизации и без использования таких средств, включая:

  • Сбор
  • Запись
  • Систематизация
  • Накопление
  • Хранение
  • Уточнение (обновление, изменение)
  • Извлечение
  • Использование
  • Передача (распространение, предоставление, доступ)
  • Обезличивание
  • Блокирование
  • Удаление
  • Уничтожение

7. Сроки обработки персональных данных

Персональные данные обрабатываются в течение:

  • Срока действия согласия субъекта персональных данных
  • Срока, необходимого для достижения целей обработки
  • Срока, установленного законодательством
  • До момента отзыва согласия субъектом персональных данных

После истечения срока обработки персональные данные подлежат удалению или обезличиванию, если иное не предусмотрено законодательством.

8. Передача персональных данных третьим лицам

Оператор может передавать персональные данные третьим лицам в следующих случаях:

  • Субъект персональных данных дал согласие на такие действия
  • Передача необходима для предоставления услуг (платежные системы, партнеры)
  • Передача предусмотрена законодательством
  • По запросу уполномоченных органов
  • Для защиты прав и законных интересов Оператора

9. Меры по защите персональных данных

Оператор применяет следующие меры для защиты персональных данных:

  • Шифрование данных при передаче (HTTPS/TLS)
  • Безопасное хранение данных на защищенных серверах
  • Ограничение доступа к данным
  • Использование средств защиты информации
  • Регулярное обновление систем безопасности
  • Мониторинг и предотвращение несанкционированного доступа
  • Обучение сотрудников правилам работы с персональными данными

10. Права субъектов персональных данных

Субъект персональных данных имеет право:

  • Получать информацию, касающуюся обработки его персональных данных
  • Требовать уточнения, блокирования или уничтожения персональных данных
  • Отозвать согласие на обработку персональных данных
  • Обжаловать действия или бездействие Оператора в уполномоченный орган
  • Получить информацию о сроках хранения персональных данных

11. Порядок реализации прав субъектов персональных данных

Для реализации своих прав субъект персональных данных может направить запрос Оператору по адресу: privacy@heymoney.ru

Запрос должен содержать:

  • ФИО субъекта персональных данных
  • Номер основного документа, удостоверяющего личность
  • Сведения о дате выдачи указанного документа и выдавшем его органе
  • Сведения, подтверждающие участие субъекта в отношениях с Оператором
  • Подпись субъекта персональных данных

12. Cookies и аналогичные технологии

Сервис использует cookies и аналогичные технологии для обеспечения функциональности и улучшения пользовательского опыта. Подробная информация о cookies содержится в Политике конфиденциальности.

13. Изменения в Политике

Оператор вправе вносить изменения в настоящую Политику. Актуальная версия всегда доступна на сайте. Существенные изменения доводятся до сведения пользователей.

14. Контакты

По вопросам обработки персональных данных обращайтесь: privacy@heymoney.ru
