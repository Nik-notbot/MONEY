# Медиафайлы для инструкций

## Структура папок

### RedotPay
- `instructions-redotpay/photos/` - папка для фотографий
  - `photo1.jpg` - Шаг 1: Вход в аккаунт
  - `photo2.jpg` - Шаг 2: Выбор раздела кошелька
  - `photo3.jpg` - Шаг 3: Выбор криптовалюты и сети
  - `photo4.jpg` - Шаг 4: Копирование BEP-20 адреса

- `instructions-redotpay/videos/` - папка для видео
  - `video1.mp4` - Видео инструкция

## Как загрузить файлы

1. Загрузите фото в папку `instructions-redotpay/photos/` с именами:
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
   - `photo4.jpg`

2. Загрузите видео в папку `instructions-redotpay/videos/` с именем:
   - `video1.mp4` (или `video1.webm`)

3. Файлы будут автоматически отображаться на странице инструкции RedotPay

## Форматы файлов

- **Фото**: JPG, PNG, WebP
- **Видео**: MP4, WebM
