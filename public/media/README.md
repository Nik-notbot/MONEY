# Медиафайлы для инструкций

## Структура папок

### Wise
- `instructions-wise/photos/` - папка для фотографий
- `instructions-wise/videos/` - папка для видео

### ByBit
- `instructions-bybit/photos/` - папка для фотографий
- `instructions-bybit/videos/` - папка для видео

### RedotPay
- `instructions-redotpay/photos/` - папка для фотографий
  - `photo1.jpg` - Шаг 1: Вход в аккаунт
  - `photo2.jpg` - Шаг 2: Выбор раздела кошелька
  - `photo3.jpg` - Шаг 3: Выбор криптовалюты и сети
  - `photo4.jpg` - Шаг 4: Копирование BEP-20 адреса
- `instructions-redotpay/videos/` - папка для видео
  - `video1.mp4` - Видео инструкция

### Grey
- `instructions-grey/photos/` - папка для фотографий
- `instructions-grey/videos/` - папка для видео

### Revolut
- `instructions-revolut/photos/` - папка для фотографий
- `instructions-revolut/videos/` - папка для видео

### Neteller
- `instructions-neteller/photos/` - папка для фотографий
- `instructions-neteller/videos/` - папка для видео

## Как загрузить файлы

1. Загрузите фото в соответствующие папки `photos/` каждого сервиса
2. Загрузите видео в соответствующие папки `videos/` каждого сервиса
3. Файлы будут автоматически отображаться на страницах инструкций

## Форматы файлов

- **Фото**: JPG, PNG, WebP
- **Видео**: MP4, WebM
